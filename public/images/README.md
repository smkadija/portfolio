# Profile & Project Images Guide

You can easily replace images without touching any code!

## Profile Images:
Place your real profile photos in `public/images/profile/`:
- `profile-main.jpg` (Used in Hero section and prominent cards)
- `profile-about.jpg` (Used in About section)

## Project Images:
Place your real project screenshots or design mockups in their corresponding directories in `public/images/projects/`:
- `coffee-app/` (e.g. `thumbnail.jpg`, `01.jpg`, `02.jpg`)
- `vpn-app/`
- `zyra/`
- `smart-city/`
- `my-lu/`
- `weather-app/`
- `graphic-design/`
- `shopify/`

The website automatically checks for these images and displays them with high-fidelity editorial framing, perfect aspect ratio, and smooth hover effects. If an image file is not yet uploaded, a clean, high-contrast branded card layout is rendered so the site always looks impeccable.
